Bocchi cursor assets converted from the user-provided Bocchi.zip package.
The original package states that the assets are for learning and communication only and must not be used commercially.
ANI frames were converted to transparent animated PNG files; the first frames of the default, pointer, and text cursors are retained as CUR fallbacks.
Animated PNG files use no-disposal full-frame composition so blink and gesture frames never clear the rest of the cursor.
